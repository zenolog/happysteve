구성
4개 스테이지 / 8장 이야기 일러스트 / 자체 합성 SFX 19개 / 엔딩
적과 아군 12종은 투명 배경의 제작 이미지로 표시됩니다. 중간보스는 일반 적 이미지를 1.25배 크기로 사용합니다. SFX는 외부 샘플 없이 합성했습니다.
그림은 AI로 생성한 일러스트입니다.
글꼴은 Google Fonts의 Jua 및 Noto Sans KR을 사용하며, 연결할 수 없으면 기기 글꼴로 표시됩니다.

검증
경제·진화 해금·타깃 선택·붙잡기·광역 마비·패배·4스테이지 클리어 자동 테스트 통과.
데스크톱 브라우저에서 드래그 배치·전투·배속·일시정지·재시작 확인.
실제 휴대폰의 터치 및 사용자 MP3 재생은 사용자 환경에서 최종 확인이 필요합니다.

업데이트 v2
- 아군 4종, 일반 적 4종, 최종 보스 4종을 이미지로 교체.
- 기존 각 웨이브의 적 체력 × [2 + 0.5 × (웨이브 번호 - 1)]. 보스에도 같은 배율 적용.
- 매 웨이브의 일반 적 뒤에 중간보스 1마리 등장. 마지막 웨이브에는 그 뒤에 최종 보스 등장.
- 중간보스 HP = 반올림[(해당 웨이브 일반 HP + 해당 웨이브 보스 기준 HP) / 2].
- 크기: 일반 적 44 / 중간보스 55 / 최종 보스 66 (지도 좌표 기준 높이).
- 중간보스는 학생이 붙잡을 수 있으며, 처치 보상은 일반 적의 3배.
- 아군 능력, 배치비, 시작 골드, 기존 SFX 및 MP3 연결 방식 유지.

업데이트 v3
- 최종 보스가 출구에 도착하면 하트 5개 차감. 남은 HP를 유지한 채 입구로 즉시 돌아옵니다.
- 보스를 처치해야 마지막 웨이브를 클리어합니다. 계속 놓치면 하트가 0이 되어 게임오버됩니다.
- 복귀 자체로 처치 보상이나 웨이브 완료 보상은 지급되지 않습니다.
- 일반 적과 중간보스는 출구에 도달하면 하트 1개 차감 후 사라집니다.

업데이트 v4

- 작은 세로 화면에서도 이야기 그림 영역이 축소되거나 잘리지 않도록 크기를 명시했습니다.

업데이트 v5
